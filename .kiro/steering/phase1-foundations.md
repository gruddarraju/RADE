# Phase 1: Starter → Hackathon Finisher (6 Weeks)

## Goal

Learn foundational skills quickly — Unix, SQL, Python, PySpark & AWS — and build a real-world production-grade project with real data.

## Learning Modules

1. **RADE Success Blueprint** — Orientation and roadmap
2. **Unix & Cloud Foundations for Data Engineers** — Linux CLI, AWS basics, IAM, S3, EC2
3. **SQL & RDS Foundations for Data Engineers** — SQL fundamentals, Amazon RDS, schema design
4. **Python & AWS Lambda Foundations for Data Engineers** — Python scripting, Lambda functions, event-driven patterns
5. **PySpark Skill Booster for AWS Data Engineering** — PySpark basics, DataFrames, transformations
6. **Building Data Engineering Code with Agentic AI** — Using AI tools for code generation
7. **Agentic Data Engineering with Amazon Q** — Amazon Q for data engineering workflows
8. **AWS Data Engineering Project Labs** — Hands-on guided labs
9. **AWS Data Engineering Deep Dive** — Advanced AWS data services

## Hackathon Deliverables

After completing the learning modules, implement a production-grade project:

- Ready with a **Project Interview Story** (STAR format)
- Ready with **Resume and LinkedIn content** for the project
- Working, deployed data pipeline on AWS

## Key Skills Gained

- Linux command line proficiency
- SQL querying and database design
- Python scripting and AWS Lambda
- PySpark data transformations
- AWS services: S3, RDS, Lambda, IAM
- AI-assisted development workflows

## When Helping with Phase 1 Work

- Focus on AWS fundamentals and best practices
- Use Python 3.x with type hints where appropriate
- Follow PySpark DataFrame API (avoid RDD unless necessary)
- Structure Lambda functions with proper error handling and logging
- Use Infrastructure as Code patterns (CloudFormation or CDK) when deploying
- Keep solutions simple and foundational — avoid over-engineering
