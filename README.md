# RADE - Real Applied Data Engineering

A structured, project-driven journey to becoming a highly-paid Data Engineer on AWS.

## Journey Overview

| Phase | Duration | Focus |
|-------|----------|-------|
| Starter → Hackathon Finisher | 6 Weeks | Foundations (Unix, SQL, Python, PySpark, AWS) + First Project |
| Applied Data Engineering Mastery | 3 Months | Spark, Data Warehousing, Lakehouse Deep Dives |
| DEH Hall of Fame | 3 Months | Streaming, CI/CD, Interview Acceleration |

**Modules**:
- RADE Success Blueprint
- Unix & Cloud Foundations for Data Engineers
- SQL & RDS Foundations for Data Engineers
- Python & AWS Lambda Foundations for Data Engineers

- Building Data Engineering Code with Agentic AI
- Agentic Data Engineering with Amazon Q
- AWS Data Engineering Project Labs
- AWS Data Engineering Deep Dive

**Outcome**: Production-grade project + interview story + resume/LinkedIn content

- Spark DataFrame Mastery
